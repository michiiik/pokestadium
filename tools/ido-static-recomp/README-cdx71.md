# ido-static-recomp — instrumented IDO 7.1 (cdx71)

Project copy of [decompals/ido-static-recomp](https://github.com/decompals/ido-static-recomp)
at commit `d5aec59932034b8a20f23f471297a55c45dcbc45` (2025-07-05; the `.git` directory is not
carried, `tools/rabbitizer` source is). Upstream files are unmodified; everything added lives in
`cdx71/`, `build/7.1-traced/` and this README.

The instrumented passes are **diagnostic oracles only**. Stadium builds keep using the repo's own
`tools/ido/<os>/7.1`. A forced object (`CDX_FORCE`) is never a decompilation result.

## Switches

uopt (`CDX_*`; grammar identical to decomp-workbench `docs/compiler-instrumentation.md`):

| Variable | Effect |
|---|---|
| `CDX_LOG=1` | `[CDX] p1cand/p1dec/p1color/p2dec/p2color/...` records: each web's save (priority), nocs, interference count, best color, forbidden mask, tie set |
| `CDX_PROC=N` | restrict to the N-th globalcolor invocation (0-based, = procedure order in the TU). A name is refused and a `procindex` table is printed |
| `CDX_DETAIL_WEB=N\|all` | `webdetail` (IR identity, bb, line), every color cost, and (for N) interference neighbours |
| `CDX_FORCE=p1:w9=c30,p2:w55=s` | force a color / the split path; needs `CDX_PROC`; forbidden colors are declined with a `force_declined` record |
| `CDX_LINEAGE_TABLES=688,1004\|all` | live-range creation (`lineage_range`) and members (`lineage_member`) for these ICHAIN tables |
| `CDX_SYMTAB=1` | itable dump (`symtab`) once per procedure — what `sym=` indexes; the frame layout reader `trace-frame` consumes it |
| `CDX_TEMPS=1` | every `f_gettemp` result (`temp`) and the temp list at globalcolor entry (`templist`) — spill/stack temps with frame offsets |
| `CDX_NODES=1` | basic-block graph nodes (`node`) with creation line |
| `CDX_UCODE=1` | every u-code record uopt reads (`ucode`, op + 8 raw words); not filtered by `CDX_PROC` |
| `CDX_CMDUMP=1` | hook in `f_optinit`: sets uopt's `-zdbug` level to 3 and opens the listing, turning on uopt's own dumps incl. `f_printcm` (code motion) |
| `CDX_CMFILE=path` | listing file for `CDX_CMDUMP` (default `uoptlist` in the compiler's cwd) |
| `CDX_OUT=path` | write `[CDX]` records to a file instead of stderr (use an absolute path) |

ugen: `DKWB_UGEN_TRACE=1` (`DKWB-CALL`, `DKWB-FREELIST` with `proc=`, `emitted=`, `line=`),
`DKWB_UGEN_SCHED=1` (`DKWB-EMIT-V1`). Output goes to stderr.

## Gate (2026-10-08, Linux x86-64, gcc -Os, pokestadium `5f838c8a`)

`bash cdx71/gate.sh <pokestadium> <recomp>/cdx71/controls/micro.c src/fragments/lab_pc/lab_pc_1AE680.c
src/fragments/lab_pc/lab_pc_1A9780.c src/fragments/lab_pc/lab_pc_1B4EA0.c` — all 16 cells
IDENTICAL (`.text .rodata .data .sdata .bss`, relocations, symbols) for: instrumented with logging
off; stage-2 binary; every switch on; `CDX_CMDUMP=1`.

Positive controls (microcase: loop with a call, 6 callee-saved webs):
- six p1 decisions colored c14–c19 = `s0`–`s5`, the object's six s-registers;
- `p1:w0=c21` moved the sum web to `s7` (`move s7,zero; addu s7,s7,v0`); `p1:w25=c20` introduced `s6`;
  `p1:w13=c16` swapped `s1`/`s2`; c22 produced `s8`. Caller-saved c1–c13 were **not** force-proved on 7.1
  (`p1:w3=c2` was byte-inert);
- `p1:w10=c4` against a forbidden mask produced `force_declined` and a normal object;
- ugen `line=` reads 3/4/5 and `emitted=` increases from 1 (the 5.3 addresses read ASCII garbage on 7.1);
- node/webdetail/lineage lines 3 (entry) and 5 (loop) match the source;
- `decomp-workbench trace-globalcolor`, `trace fifo`, `trace-emit` parse the logs.

Observed, not yet explained: with the sum web forced to `s7`, the prologue saved every register
`s0`–`s7` although `s5`/`s6` carry nothing. That fits "save a contiguous range up to the highest
s-register used", but one microcase is too little to treat it as a rule.
